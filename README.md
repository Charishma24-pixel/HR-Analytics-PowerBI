# HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive HR Analytics Dashboard built using Power BI. The dashboard helps analyze employee data and provides insights into workforce distribution, salaries, and departments. It demonstrates Power BI, Power Query, DAX, and data visualization skills.

---

## 🛠 Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

---

## 📊 Dashboard Features

### KPI Cards
- Total Employees
- Total Salary
- Average Salary
- Highest Salary
- Lowest Salary
- Number of Departments

### Visualizations
- Department-wise Employee Count
- Department-wise Average Salary *(In Progress)*
- Gender Distribution *(In Progress)*
- Job Role Analysis *(In Progress)*
- Age Group Analysis *(In Progress)*

---

## 📈 Business Insights

This dashboard helps HR teams:

- Understand workforce distribution across departments.
- Identify departments with the highest and lowest employee counts.
- Analyze salary trends.
- Support workforce planning and hiring decisions.
- Monitor key HR metrics using interactive visuals.
